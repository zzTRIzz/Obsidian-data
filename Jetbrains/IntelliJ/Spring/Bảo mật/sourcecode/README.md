# Dự án học Spring Security với JWT

Đây là phiên bản đơn giản để học về Spring Security và JWT authentication.

## Cấu trúc dự án

- `config/` - Cấu hình Spring Security và JWT
- `controller/` - REST Controllers
- `service/` - Business Logic
- `model/` - Data Models
- `dto/` - Data Transfer Objects

## Tính năng chính

1. **JWT Authentication** - Xác thực bằng JSON Web Token
2. **User Registration** - Đăng ký tài khoản mới
3. **User Login** - Đăng nhập hệ thống
4. **Role-based Authorization** - Phân quyền theo vai trò
5. **Protected Endpoints** - Các API được bảo vệ

## Các khái niệm học được

- Spring Security Configuration
- JWT Token Generation & Validation
- Password Encoding với BCrypt
- CORS Configuration
- Authentication Filter
- Authorization Rules
